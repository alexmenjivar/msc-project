# Cancer Gene Expression Feature Selection using Differential Evolution and Hill Climbing

This repository contains the implementation and experiments for my MSc Advanced Computing project.

The project investigates feature selection for high-dimensional cancer gene-expression datasets. The main pipeline combines Information Gain filtering with Differential Evolution (DE) and Hill Climbing (HC). The experiments evaluate whether HC can improve the gene subsets produced by DE and compare the resulting subsets across several classifiers.

Three datasets are used:

- CNS
- Lung
- Breast

The final evaluation uses nested cross-validation. Filtering, DE and HC are performed using the outer training data, so the held-out outer test data does not influence which genes are selected.

## Feature Selection Pipeline

The main feature-selection process consists of three stages:

1. Information Gain filtering retains the top 5% of genes.
2. Differential Evolution searches for a smaller gene subset.
3. Hill Climbing can refine the subset returned by DE.

Hill Climbing is also tested directly after the Information Gain filter to examine whether DE is necessary before local refinement.

Five experimental configurations are compared:

- `NoSelection` – all available genes are used without feature selection.
- `LongDE` – Information Gain followed by a longer DE search.
- `ShortDE` – Information Gain followed by a shorter DE search.
- `ShortDE_HC` – Information Gain, Short DE and Hill Climbing.
- `FilterHC` – Information Gain followed directly by Hill Climbing.

## Evaluation

The experiments use nested cross-validation. For each outer fold, the Information Gain filter is fitted using the outer training data. DE and HC then search within the resulting filtered feature space using three-fold stratified cross-validation to calculate fitness. The outer test data is kept separate throughout feature selection and is used only for the final classifier evaluation.

The number of outer folds is:

- CNS: 5 folds
- Lung: 5 folds
- Breast: 3 folds

Each configuration is repeated using random seeds `0`, `1` and `2`.

Five classifiers are evaluated:

- Linear Support Vector Machine (SVM)
- K-Nearest Neighbours (KNN), k=5
- Gaussian Naive Bayes
- Decision Tree
- Random Forest

Performance is reported using Accuracy and Macro-F1.

## Dataset Preparation

The datasets are stored as CSV files in the `data/` directory.

CNS and Lung do not require missing-value imputation.

Breast contains missing values. During the final experiment, genes containing no available values in an outer training fold are removed. The remaining missing values are handled using median imputation fitted only on the outer training data. This prevents information from the outer test fold from entering the feature-selection process.

The `src/data_quality.py` script contains the dataset inspection used during data preparation.

## Differential Evolution

The DE implementation is contained in `src/de.py`.

Candidate subsets are represented as binary vectors, where `1` indicates that a gene is selected and `0` indicates that it is excluded.

The final experiments use dataset-specific population sizes and generation limits:

| Dataset | Population | Short DE | Long DE |
| ------- | ---------: | -------: | ------: |
| CNS     |         50 |        8 |      30 |
| Lung    |         25 |        6 |      20 |
| Breast  |         25 |        5 |      15 |

The crossover rate is 0.9.

## Hill Climbing

The HC implementation is contained in `src/hill_climbing.py`.

HC uses Steepest Ascent. At each step, all one-gene changes to the current subset are evaluated and the best improving neighbour is selected. The search stops when no improvement is found or when the maximum number of steps is reached.

The maximum number of HC steps is:

- CNS: 15
- Lung: 4
- Breast: 4

## Running the Main Experiment

From the project root, run:

```bash
python experiments/full_comparison.py
```

The results are written to:

```text
results_full.csv
```

A complete run produces 225 result rows from the combination of three datasets, five configurations, three random seeds and five classifiers.

At the start of each run, any existing `results_full.csv` file is removed automatically. The script then writes the results of the new experiment, preventing results from previous runs from being duplicated.

## Regenerating Supporting Figures

The confusion matrices used in the project can be regenerated by running:

```bash
python experiments/regenerate_figures.py
```

This creates:

```text
cm_cns.png
cm_lung.png
cm_breast.png
```

For CNS, the generated figure uses the neutral labels `Class 0` and `Class 1` because the biological meanings of the original encoded classes could not be established reliably from the available dataset documentation.

## Runtime Estimate

The computational-cost test can be run with:

```bash
python experiments/runtime_estimate.py
```

This measures representative DE and HC execution times and provides approximate runtime estimates for the complete experiment.

## Reproducibility

Fixed random seeds are used throughout the final experiments. The main comparison uses seeds `0`, `1` and `2`.

To reproduce the final results, run `experiments/full_comparison.py` from the project root. The script will create a fresh `results_full.csv` for the new run.
